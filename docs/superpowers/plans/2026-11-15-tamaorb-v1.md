# TamaOrb v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Firmware that runs Tamagotchi P1/P2 ROMs on the SpotPear 1.28" ESP32-S3 ball. It is always on, survives power cuts, catches up from NTP, loads ROMs from SD, has a USB host tool, and handles low battery.

**Architecture:**
- An ESP-IDF 6.1.1 project in C.
- **Portable components** (`tama_core`, `ui`, `persist`, `hostlink` protocol) never include ESP-IDF or board headers, and build on Linux with Unity tests.
- **Device code:** board, net, power, storage and the app glue in `main/`.
- **tamalib** is an unmodified git submodule.
- **Tasks:** the emulator runs in its own task on core 1. UI, Wi-Fi, saving and the USB link run on core 0.

**Tech Stack:** ESP-IDF v6.1.1 (`esp_lcd` + `espressif/esp_lcd_gc9a01`, `espressif/esp_codec_dev`, `sdmmc`/`fatfs`, `esp_wifi`, `esp_netif_sntp`, `nvs_flash`, `esp_pm`), tamalib @ `ce304d5`, Unity v2.6.0 (host tests), Python 3 + pyserial + pytest (host tool).

**Spec:** `docs/superpowers/specs/2026-11-15-tamaorb-design.md`. Read it with this plan; § numbers below refer to it. Visual reference: the "TamaOrb Display" design canvas linked from spec §5.1.

## Global Constraints

- License **GPL-3.0-or-later**. Every new source file starts with an SPDX header: `// SPDX-License-Identifier: GPL-3.0-or-later`.
- Never commit ROMs, `*.bin` outside `test/fixtures/`, `hw-backup/`, or Bandai/MAME/TamaTool artwork. `.gitignore` already enforces most of this.
- ESP-IDF **v6.1.1** (installed at `~/esp/esp-idf-v6.1.1`; `export.sh` needs bash: `bash -c '. ~/esp/esp-idf-v6.1.1/export.sh && idf.py build'`).
- Target `esp32s3`, 16 MB flash, CPU 240 MHz, `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`, `CONFIG_FREERTOS_HZ=1000`.
- Dependencies: only ESP-IDF, its official managed components named above, tamalib, Unity (tests), pyserial/pytest (tool). Nothing else.
- tamalib sources compile with `-Wno-error=maybe-uninitialized` (upstream bug, spec §4). Never edit the submodule.
- `tamalib_init()` is called at most **once per boot** on device. Reset in tests goes through the boot snapshot (Task 3).
- Supported ROMs (12,288 bytes, 16-bit big-endian words, 12 bits used):
  - P1 SHA-1 `4b4979cf92dc9d2fb6d7295a38f209f3da144f72`
  - P2 SHA-1 `09e5101b37636a314fc599d5d69b4846721b3c88`
  - Ignore test ROM `6e13d015113e16198c0059b9d0c38d7027ae7324`.
  - Everything else is unknown and rejected.
- Pins (spec §3), used only in `components/board/spotpear_ball_128/`:
  - LCD: SCLK 4, MOSI 2, CS 5, DC 47, RST 38; BL 42, active low.
  - Touch: SDA 11, SCL 7, RST 6, INT 12, address 0x15.
  - Codec I2C: SDA 15, SCL 14; ES8311 at 0x18.
  - I2S: MCLK 16, BCLK 9, WS 45, DOUT 8, DIN 10; amp enable 46.
  - SD (SDMMC 1-bit): CLK 17, CMD 18, D0 21.
  - Battery ADC: GPIO1 (ADC1_CH0, 12 dB, divider ×2). USB present: GPIO41. BOOT: GPIO0. GPIO3 driven HIGH at boot.
- Screen geometry (device px):
  - 240×240 circle, black outside it.
  - LCD pixel (px,py) is a 5×5 square at x=24+6·px, y=72+6·py.
  - Icons are 12×12 cells at 2 px each (24×24). Top-row centres are (57,48), (97,48), (143,48), (183,48); the bottom row uses the same x at y=192.
  - Touch zones: x<80 → A, 80–159 → B, ≥160 → C.
- Classic palette (RGB565): bg `0xB613` (#B6C19E), ink `0x1923` (#1C2518), ghost `0xA591` (#A5B08F, bg mixed 11% toward ink), held-zone tint = bg mixed 10% toward ink.
- Timing defaults:
  - screen timeout 30 s;
  - save 3 s after the last button release, and every 5 min;
  - catch-up progress saved every 2 min of wall time;
  - NTP wait at boot 15 s;
  - low battery when < 3400 mV on battery;
  - low-battery deep-sleep wake every 60 s.

## Review Focus

1. **Power cut mid-save or mid-catch-up.** The next boot must load the previous good save, and catch-up resumes from the last progress save, not from zero. Pinned in Task 8 (corrupt record rejected) and Task 16 (progress saves carry virtual time).
2. **tamalib's 32-bit tick counter wraps every ~36.4 h** at 32,768 Hz. Catch-ups longer than that must still replay the full gap. Pinned in Task 4.
3. **Touch edge cases:** a finger sliding across zones, two fingers in the same zone, lifting one of two fingers, and a wake-touch that keeps being held. None may leave a button stuck or press one blindly. Pinned in Task 6.
4. **The clock going backwards** (NTP time earlier than the save, or the RTC reset to 1970). This must not produce a huge or negative gap. Pinned in Task 4 (`test_gap_clock_backwards`, untrusted-time tests).
5. **Odd SD contents:** non-ROM files, oversized files, the same ROM twice, or the remembered ROM missing from the card. Boot must neither crash nor switch pets. Pinned in Task 11.

### Task 3: Emulator wrapper (`tama_core`)

**Files:**
- Create: `components/tama_core/include/tama_core.h`, `components/tama_core/tama_core.c`, `test/host/test_core.c`

**Interfaces:**
- Consumes: tamalib (Task 1), `tc_rom.h` (Task 2).
- Produces (`tama_core.h`):
  ```c
  typedef enum { TC_BTN_A = 0, TC_BTN_B = 1, TC_BTN_C = 2 } tc_button_t;   // tamalib BTN_LEFT/MIDDLE/RIGHT
  #define TC_BTN_MASK(b) (1u << (b))
  typedef struct { uint32_t rows[16]; uint8_t icons; } tc_frame_t;          // bit x of rows[y] = pixel (x,y); icons bit i = icon i
  typedef struct { uint32_t freq_dhz; bool on; } tc_tone_t;
  typedef struct {
      uint32_t (*now_us)(void);                 // monotonic, wraps at 2^32
      void     (*sleep_until_us)(uint32_t ts);  // only called in real-time mode
      void     (*lock)(void);                   // guards frame/tone/button exchange across tasks
      void     (*unlock)(void);
  } tc_platform_t;
  bool     tc_init(const uint16_t *program, const tc_platform_t *plat);     // once per process; captures the boot snapshot
  void     tc_reset_to_boot(void);                                        // restores the boot snapshot
  void     tc_set_realtime(bool realtime);                                // speed 1 vs speed 0
  void     tc_step(uint32_t n);                                           // n tamalib steps; applies posted buttons first
  void     tc_post_buttons(uint8_t mask);                                 // any task
  void     tc_get_frame(tc_frame_t *out);                                 // any task; last published frame
  bool     tc_frame_changed(uint32_t *seq);                               // any task; true when a newer frame was published than *seq; updates *seq
  void     tc_get_tone(tc_tone_t *out);                                   // any task
  uint32_t tc_tick_counter(void);                                         // raw tamalib 32,768 Hz counter
  size_t   tc_state_size(void);
  size_t   tc_state_save(uint8_t *buf, size_t cap);                       // returns bytes written, 0 on error
  bool     tc_state_load(const uint8_t *buf, size_t len);                 // false on size/version mismatch
  ```
- Frame publishing: the HAL `set_lcd_matrix`/`set_lcd_icon` write a back frame. `tc_step` publishes the back frame (under `lock`) whenever 1/30 s of emulated time has passed since the last publish, and bumps a sequence number.
- **Real-time sleeping:** `sleep_until` is batched. It only calls `plat->sleep_until_us` once the deadline is ≥ 2,000 µs ahead of `now_us()`, and returns immediately otherwise (spec §4; avoids a busy loop on every 5-cycle HALT).
- **State format:** a version byte (`1`) followed by the `state_t` fields in TamaTool `src/state.c` order and encoding (u8/u16 LE/u32 LE), then the interrupt table, `cpu_halted`, and the full `MEM_BUFFER_SIZE` memory.

- [ ] **Step 1: Write the failing tests** in `test_core.c`. Use a fake platform whose `now_us` is a counter and whose `sleep_until_us` jumps the counter to `ts`. All tests except `test_post_buttons_mask` are ROM-gated on P1.
  - `test_boots_and_draws`: after stepping until `tc_tick_counter()` advances 5×32768, the frame has ≥ 1 lit pixel.
  - `test_state_roundtrip_deterministic`:
    1. Step 2 s and save to `buf`.
    2. Step 3 s more and record the frame as F1.
    3. `tc_state_load(buf)`, step 3 s, record F2.
    4. `TEST_ASSERT_EQUAL_MEMORY(&F1,&F2,sizeof F1)`.
  - `test_reset_to_boot_unsticks`: `tc_reset_to_boot()` and stepping 1 s advances the tick counter. This guards the double-init bug.
  - `test_realtime_equals_fast`:
    1. From boot, step 10 emulated s with `tc_set_realtime(true)` and save as S1.
    2. Reset to boot and step 10 emulated s with `tc_set_realtime(false)`, saving as S2.
    3. `TEST_ASSERT_EQUAL_MEMORY(S1,S2,len)`.
  - `test_load_rejects_wrong_version`: a buffer with version byte `99` makes `tc_state_load` return false.
  - `test_post_buttons_mask`: post `TC_BTN_MASK(TC_BTN_B)`, `tc_step(1)`; the tamalib K01 pin reads low. Expose `tc_debug_input_pins()` under `#ifdef TC_TESTING`.
- [ ] **Step 2: Run.** `ctest --test-dir build-host -R core`. Expected: FAIL.

### Task 4: Catch-up runner and time arithmetic

**Interfaces:**
- Produces:
  ```c
  // tc_time.h (pure)
  #define TC_TICK_HZ 32768u
  uint32_t tc_ticks_since(uint32_t start, uint32_t now);                     // wrap-safe
  bool     tc_gap_seconds(int64_t saved_unix, bool saved_trusted,
                          int64_t now_unix, bool now_trusted, uint64_t *gap_s); // false = unknown → resume frozen; negative → 0
  ```

- `tc_catchup` sets speed 0, steps while accumulating `tc_ticks_since(prev, now)` into a `uint64_t` until `ticks` is reached, calls `cb` every `cb_every_ticks`, then restores real-time mode.

### Task 17: Hostlink protocol and device transport

**Files:**
- Create: `components/hostlink/include/hostlink.h`, `components/hostlink/hl_proto.c`, `components/hostlink/hl_base64.c`, `components/hostlink/CMakeLists.txt`, `test/host/test_hostlink.c`, `main/hostlink_task.c/.h`

**Interfaces:**
- **Protocol:** lines over the USB-Serial/JTAG console, coexisting with logs. Requests and replies start with `@TO `; every other line is ignored by both sides.
  ```
  host → @TO PUT <name> <size> <sha1hex>      device → @TO OK | @TO ERR <reason>
  host → @TO D <seq> <base64 ≤ 768 bytes>     device → @TO OK <seq>          (seq from 0, in order)
  host → @TO END                              device → @TO OK <model> | @TO ERR sha1|unknown|io
  host → @TO LIST                             device → @TO ITEM <name> <model> <sha1hex> ... then @TO OK
  host → @TO RM <name>                        device → @TO OK | @TO ERR notfound
  host → @TO WIFI <ssid_b64> <pass_b64>       device → @TO OK
  host → @TO STATUS                           device → @TO STATUS rom=<model> wifi=<0|1> time=<0|1> batt_mv=<n> usb=<0|1> sd=<0|1>
  ```
  `<name>` matches `[A-Za-z0-9._-]{1,48}` and must end in `.bin`.
- Produces (portable):
  ```c
  typedef struct {
      bool (*begin)(void *ctx, const char *name, uint32_t size);
      bool (*chunk)(void *ctx, const uint8_t *data, size_t len);
      const char *(*end)(void *ctx, const uint8_t sha1[20], const uint8_t *data, size_t len); // returns model name or NULL + sets err
      int  (*list)(void *ctx, void (*emit)(void *ectx, const char *line), void *ectx);
      bool (*remove)(void *ctx, const char *name);
      bool (*wifi)(void *ctx, const char *ssid, const char *pass);
      void (*status)(void *ctx, char *out, size_t cap);
      void *ctx;
  } hl_ops_t;
  typedef struct hl_session hl_session_t;   // opaque; holds a 12,288-byte upload buffer
  void hl_init(hl_session_t *s, const hl_ops_t *ops);
  void hl_feed_line(hl_session_t *s, const char *line, void (*reply)(void *rctx, const char *line), void *rctx);
  size_t hl_session_size(void);
  ```
  - `end` verifies the size, the SHA-1 against `<sha1hex>`, and `tc_rom_identify` ∈ {P1,P2}.
  - On device, `end` calls `rom_store_write_sd` when SD is present. Otherwise it calls `rom_store_set_active` and reboots after replying (spec §7.3, no-SD path).
