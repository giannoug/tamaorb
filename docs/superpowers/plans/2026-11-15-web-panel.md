# TamaOrb Web Panel, HTTP API and MCP: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The ball serves a settings and management page, a JSON HTTP API, and an MCP server on the LAN. Its settings become stored, live-applied values that can also be changed over USB.

**Architecture:**
- **Portable logic, host-tested, never including ESP-IDF headers:**
  - `components/settings`: the settings table, validation and the debounced-write policy.
  - `components/remote`:
    - the operations table (`rm_ops_t`);
    - the MCP JSON-RPC dispatcher;
    - the REST router;
    - the press sequencer;
    - screen text and PNG;
    - save-upload checks.
- **Device code:**
  - `components/web`: `esp_http_server`, mDNS and the embedded page.
  - `main/`: implements `rm_ops_t` on top of the existing `rom_store`, `saver`, `net`, `power`, `tama_core` and the UI.
  - Everything new runs on core 0. The emulator on core 1 is untouched, apart from one flag read in its tone callback.

**Tech Stack:**
- ESP-IDF v6.1.1 with `esp_http_server` (in IDF), plus the managed components `espressif/mdns` and `espressif/cjson`;
- cJSON v1.7.18 for the host tests, via FetchContent;
- Unity v2.6.0;
- Python 3 with pyserial and pytest.

**Spec:** `docs/superpowers/specs/2026-11-15-web-panel-design.md`. Read it with this plan; § numbers below refer to it. It builds on `docs/superpowers/specs/2026-11-15-tamaorb-design.md` (the "v1 spec").

**Visual reference:** the design canvas "TamaOrb Web Panel" at https://claude.ai/artifact/2rqMHy3QAGosXXzhTjnWaW. Its **Panel** page holds the page, the restore dialog and the restarting overlay. Its **Components** page holds the tokens and components.

## Global Constraints

**License and content**
- Every new source file starts with `// SPDX-License-Identifier: GPL-3.0-or-later`, or `#` / `<!-- -->` in non-C files.
- No ROMs, and no Bandai, MAME or TamaTool material: no manual text in the guides, no artwork.

**Build and dependencies**
- ESP-IDF **v6.1.1**: `bash -c '. ~/esp/esp-idf-v6.1.1/export.sh && idf.py build'`.
- New dependencies, and nothing else:
  - device: `espressif/mdns`, `espressif/cjson`, added with `idf.py add-dependency` so the constraint and `dependencies.lock` are committed;
  - host tests: cJSON `v1.7.18`.

**Portability and cores**
- `components/settings` and `components/remote` never include ESP-IDF, FreeRTOS or board headers. They build in `test/host`.
- Core 0 only for httpd, mDNS, the press task and the settings writer. Never add work to the emulator task, except the single atomic mute-flag read in Task 9.

**Hardware loop**
- The serial port is opened with DTR and RTS **both True**; False/False resets the ESP32-S3.
- Stop any serial reader before flashing.
- Flash with `bash -c '. ~/esp/esp-idf-v6.1.1/export.sh && idf.py -p /dev/ttyACM0 flash'`.

**Settings (§5.1), exact values**

| Key | Range | Default |
|---|---|---|
| `brightness` | 1–100 | 80 |
| `dim_level` | 0–100; effective value is `min(dim_level, brightness)` | 5 |
| `dim_usb_s` | 0 or 5–3600 | 30 |
| `dim_battery_s` | 0 or 5–3600 | 15 |
| `off_battery_s` | 10–3600 | 30 |
| `volume` | 0–100 | `CONFIG_TAMAORB_VOLUME` |
| `palette` | `classic` \| `neutral` \| `night` | `classic` |
| `name` | 1–32 of `a-z 0-9 -`, not starting or ending with `-` | `tamaorb` |
| `ntp` | 1–63 of `A-Z a-z 0-9 . -` | `pool.ntp.org` |
| `agent_feedback` | `quiet` \| `silent` \| `visible` | `quiet` |

- `name` and `ntp` apply after a restart. Everything else is live.
- A display change (`brightness`, `dim_level`, `palette`) made through the web, MCP or USB wakes the screen.
- Settings are written to NVS **2000 ms** after the last change. They live in the default `nvs` partition, namespace `settings`, one string key per setting, named exactly as the setting.
- **LCD palettes** (bg / ink, ghost = bg mixed 11% toward ink):

  | Palette | bg | ink |
  |---|---|---|
  | Classic | `#B6C19E` | `#1C2518` |
  | Neutral | `#C4C6BD` | `#22241F` |
  | Night | `#18201A` | `#A9D38E` |

**Press (§8.2)**
- Steps are `A`, `B`, `C` or `AC`, at most 32 per call.
- Timings: `hold_ms` 50–2000 (default 150), `gap_ms` 0–2000 (default 200), `settle_ms` 0–3000 (default 500).
- Limit: n·hold + (n−1)·gap + settle ≤ 10000 ms.

**HTTP (§7)**
- Request bodies over 16384 bytes are rejected with 413.
- httpd runs on core 0 with `max_open_sockets = 4` and LRU purge.
- Responses go out before any restart; the restart follows about 1000 ms later.
- A request carrying an `Origin` header that isn't the ball's own host gets 403. This applies to every non-GET request and to `POST /mcp`.

**Restore (§7.3)**
- `mode=frozen` re-stamps the save with the ball's current time and trust flag.
- `mode=replay` keeps the save's own time.
- A missing or invalid `mode` gets 400.

**Default catch-up speed** shown before one has run this boot: **24×** (measured 24.1× on 2026-11-15).

**Acceptance under load (§10.3)**
- internal-RAM minimum free ≥ 20 KB;
- emulator pace within ±0.01 s per minute;
- no failed requests at 4 parallel connections.

## Review Focus

These are the inputs most likely to bite a real user. Each is pinned by a test in the task named.

1. **A settings change with one bad value** (e.g. `{"brightness":50,"dim_level":500}`) must change nothing: no partial apply, and the error names `dim_level`. Pinned in Task 1 (`test_set_many_all_or_nothing`) and Task 8 (`test_patch_settings_bad_key_changes_nothing`).
2. **Restoring the active pet's save** must not be overwritten by the running emulator's next periodic or button save before the reboot. Pinned in Task 10, step 6 (hardware check with a button press during the restore), plus the `saver_import` freeze rule in Task 9.
3. **A malformed or hostile request** must give a clean JSON-RPC or HTTP error, never a crash or a hang. That covers bodies that are a JSON array (batch), not JSON, the wrong types, or oversized. Pinned in Task 7 (`test_batch_rejected`, `test_parse_error`, `test_tool_args_wrong_type`) and Task 10 (413 check).
4. **An uploaded save that's truncated, from another ROM, or corrupt** must be rejected with 400 and leave the pet untouched. Pinned in Task 6 (`test_save_check_*`).
5. **A button press sent while another press runs or during catch-up** must return "busy" or "catching up", with no stuck button. After any sequence ends, the agent mask is 0. Pinned in Task 5 (`test_mask_zero_after_done`) and Task 7 (`test_press_busy_is_tool_error`).

  ```c
  void (*get_settings)(void *ctx, st_settings_t *out);
  void (*put_settings)(void *ctx, const st_settings_t *s, bool display_changed);
  ```
- Protocol:
  - `@TO GET` replies `@TO SET <key>=<value>` once per key, in `st_key` order, then `@TO OK`.
  - `@TO SET k=v [k=v…]` is all or nothing:
    - success replies `@TO OK`;
    - failure replies `@TO ERR <first bad key>`;
    - a pair without `=` replies `@TO ERR data`.
  - Values contain no spaces. Every setting satisfies this.
- Tool:
  - `tamaorb-rom.py get` prints `key=value` lines.
  - `tamaorb-rom.py set k=v …` prints `ok`. On failure it exits 1 with `rejected: <key>`.

  ```c
  esp_err_t web_start(const rm_ops_t *ops, const char *hostname);  // mDNS + httpd; call once, after net_start
  ```
- **`net_start`:** sets the DHCP hostname (`esp_netif_set_hostname`) before connecting, and uses `ntp_server` in `ESP_NETIF_SNTP_DEFAULT_CONFIG`.
- **`web_start`:**
  - `cJSON_InitHooks` with `heap_caps_malloc(…, MALLOC_CAP_SPIRAM)`;
  - mDNS hostname `hostname`, service `_http._tcp` on port 80;
  - httpd config: `core_id 0`, `max_open_sockets 4`, `lru_purge_enable true`, `stack_size 6144`, `uri_match_fn httpd_uri_match_wildcard`;
  - handlers: `GET /` (the page; Task 11 fills it, until then a one-line HTML stub), `POST /mcp`, `GET /mcp` → 405, and `/api/*` for GET/POST/PUT/PATCH.
  - Bodies over 16384 → 413 before reading. Bodies are read into a PSRAM buffer.
- **`sdkconfig.defaults`** adds:
  - `CONFIG_LWIP_TCPIP_TASK_AFFINITY_CPU0=y`;
  - `CONFIG_ESP_WIFI_TASK_PINNED_TO_CORE_0=y`;
  - `CONFIG_HTTPD_WS_SUPPORT=n`.
  - Delete `sdkconfig` locally and rebuild, so the defaults apply.
- **`app_main`:**
  - after `settings_init`, call `net_start(s.name, s.ntp)`;
  - after `saver_load` and before `emu_start`, call `press_task_start()` and `web_start(remote_ops_init(model, sha1), s.name)`.
