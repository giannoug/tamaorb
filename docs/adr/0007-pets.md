# ADR 0007: Pets are a ROM plus a number; the one on screen runs

**Context.** The owner wanted as many pets as they like, from any supported ROM, and a choice between fast-forwarding and resuming a pet that comes back after time away. The emulator owns core 1, so only one pet can run at a time. ADR 0004 had already put a pet number in the save key.

**Decision.**
- **A pet is a ROM's SHA-1 plus a number 0-9** (the digit `ps_key` already writes), so up to ten pets per ROM. Its saves stay where ADR 0004 put them.
- **Names, the active pet and the previous pet** live in a `pets` namespace of the `tamaorb` partition: a name entry per pet (`n<10 hex of the SHA-1>_<digit>`), `active` and `prev` records. A pet exists if it has a name entry or a save, so saves written before pets had names show up as pets with an automatic name ("P1 #1").
- **Only the pet on screen runs.** The others stay frozen at their last save. Switching saves the running pet, records it as `prev`, sets `active` and restarts.
- **Boot pick.** The recorded active pet runs if it is the cached ROM's and still exists; otherwise the ROM's pet with the newest save (trusted times first), else its lowest pet, else a new pet 0 (`ps_pick_for_rom`). This covers a first start, a USB push with no SD card, and a record lost to a power cut.
- **A gap of a minute or more asks** (Resume / Fast-forward, and Back after a switch) and waits in `EMU_WAIT`; the pet doesn't run or save meanwhile. Shorter gaps fast-forward silently. Resume and Skip set the pet's clock afterwards. The `prev` record lasts until the question is answered, so a restart while it waits asks again with Back; Back shows only while its pet exists and its ROM is on the card. The first answer wins (ball or web panel).
- **No compatibility layer** for firmware older than this (the project is unreleased): the ROM cache keeps its keys with either size, and older builds reading this NVS aren't catered for.

**Consequences.**
- No migration step: the owner's existing saves became pet #1 of their ROMs on the first boot.
- A pet whose ROM file left the card is listed but can't be switched to; the running one keeps running from the cached ROM.
- Ten pets per ROM is the key format's limit; NVS space is the other one (each pet is about 2.2 KB of saves).
