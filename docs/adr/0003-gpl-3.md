# ADR 0003: GPL-3.0-or-later

**Context.** tamalib is GPL-2.0-or-later and ESP-IDF is Apache-2.0. Apache-2.0 is incompatible with GPL-2.0-only.

**Decision.** License TamaOrb as GPL-3.0-or-later. That's compatible with both, using tamalib's "or later" clause.

**Consequences.** Contributions are GPL-3.0-or-later. No ROMs and no Bandai, MAME or TamaTool artwork are ever committed. The only third-party art stored is agg23's CC0 icon sheet, kept as a reference in `docs/references/icons/`.
