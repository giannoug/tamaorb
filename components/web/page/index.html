Agents

An agent on your network can read the pet's screen, press buttons and change these settings. Add the ball to Claude Code once:
claude mcp add --transport http tamaorb http://tamaorb.local/mcp
When an agent presses buttonsPresses never wake the screen. Most presses make the pet click; choose what those clicks do.
